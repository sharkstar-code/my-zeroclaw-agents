Intro Track

Week 1

Infrastructure

Unix knowledge (bash specifically) assisted with getting the linode set up properly.

Model choice was a shot in the dark, opted for Haiku 4-5 mainly because it was cheap, and by looking ahead at the various tasks it would be used for my sense was that it would be sufficiently capable. This turned out to be mostly true.

Telegram setup mostly OK. Distinction between bot display name and username somewhat confusing and I ended up with a display name ending in bot also, but it didn't seem to matter.

Config

Cost config doesn't seem to work at all in ZeroClaw. Set global cost limits as per the instructions but the event log continues to record all event costs as zero. Suspect it might not be picking up correct model being used, or the feature is just not working. Fallback is cost monitoring and control in OpenRouter.

Cron

Request to set up a one-off cron job was misinterpreted and ended up with a repeating job. Perhaps showing the dumbness of the model. Fixable with more precise instructions.

Security

I have security monitoring enabled and the audit is supposed to be captured to a file called audit.log but I can't find it anywhere

Week 2

Agent Workspace Provision

I configured auto-approve for file_write etc. but Zeroclaw still occasionally comes back to me in Telegram for file write approval. Not a big issue, but inconsistent behaviour.

Agent Skills

In testing, kept hitting context limits for tasks. Four things helped: - Increasing token context in config - Limiting the number of files the agent is asked to process at a time (SKILL.md) - Writing out to files in chunks rather than all at once (SKILL.md) I had an issue where my concierge agent (genie) was writing out archive files per event rather than aggregating them under a single keyword topic, so that had to be tightened up in skill.md.

Genie

I built my concierge agent, genie, to solve a real-world 'problem' for myself, whilst doing something very close in spirit to what luna was doing. She requires further work in terms of how data is summarised (see note above) but feels like the foundation of something that might actually be useful to me on a weekly basis.

Week 3

Installing mkdocs

Pip install didn't work out of the box, had to install Developer Tools to get Python. Then needed pip3 install (rather than just pip). Didn't use sudo so mkdocs installed into my user directory on Mac, which meant I had to add it to my path via .zshrc.

Markdown

Obsidian and mkdocs have different markdown standards for bulleted lists. Basically, mkdocs requires an extra space (to 4 spaces) before a bullet under a numbered list to render properly.
